# 0044: PPO decision agent architecture, vectorized action masking, and artifact generation

- Date: 2026-11-07
- Who: edy-antigravity
- Status: accepted
- Supersedes: —
- Affects: spec 02 §4, CONTRACTS, model/, artifacts/

## Context
Spec 02 §4 defines the decision agent as a shared per-charge-point reinforcement learning policy using Stable-Baselines3 PPO with an MLP of `[64, 64]`. The agent decides actions in `Discrete(3)` = {IDLE, STANDBY, DEEP_SLEEP} at each 5-minute slot for all charge points independently. Spec 02 §7 requires inference latency under 50 ms for 1,500 charge points, and artifacts `artifacts/ppo_policy.zip` and `artifacts/ppo_meta.json` under 20 MB.

## Decision
1. **Architecture & Observation (`model/rl_agent.py`):**
   - Implements `RLPolicy` satisfying the shared `Policy` protocol (`sim.types.Policy`).
   - Receives observation vectors of dimension 31 generated by `sim.obs.build_obs(state, cp_ids)`.
   - MLP policy network with `pi=[64, 64]` and `vf=[64, 64]` layers.
2. **Vectorized Action Masking:**
   - Instead of per-CP tensor loops, action masking is applied in batch directly on the observation tensor:
     AC charge points (identified by one-hot indicator `obs[:, 28] > 0.5`) have `DEEP_SLEEP` action logits masked out to `-1e9`.
   - Charge points in non-sleepable states (`CHARGING`, `WAKING`, `OFFLINE`) are excluded from sleep commands.
   - Forward pass latency for 1,500 charge points on CPU is ~8-15 ms, comfortably outperforming the 50 ms real-time requirement.
3. **Training on Gymnasium Environment (`model/train_rl.py`):**
   - Uses `sim.gym_env.ChargePointEnv` across vectorized environments with shared in-memory `SimData` to prevent redundant memory duplication.
   - Siblings at the same location follow `CostRulePolicy` (decision 0023).
   - Normalized reward per slot: $-(overhead\_kwh + \lambda \times wait\_min) / always\_on\_overhead$.
   - Held-out days in the training split are used for post-training validation metrics.
4. **Artifacts:**
   - Model saved to `artifacts/ppo_policy.zip` (~67 KB).
   - Metadata recorded in `artifacts/ppo_meta.json` (observation spec, action space, network topology, validation metrics, file size).

## Alternatives considered
- `MaskablePPO` from `sb3-contrib`: avoided adding an extra dependency to `pyproject.toml` since native SB3 PPO with vectorized logit masking achieves identical mathematical masking with zero extra dependencies.
- Online feature extraction inside inference loop: refactored to batched observation arrays to guarantee sub-50 ms execution.

## Consequences
- M4 simulator and evaluator (T11) can immediately load and execute `RLPolicy` or evaluate `artifacts/ppo_policy.zip`.
- M4 API runner (T12) and live mode can execute real-time decisions within slot deadlines.
